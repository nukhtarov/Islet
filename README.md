# Islet

Субтитры и текст с телефона в вырезе (notch) MacBook — как Dynamic Island.

## Сборка и запуск

```bash
./build.sh
open Islet.app
```

Нужны только Command Line Tools (Xcode не обязателен), macOS 14+.

## Как пользоваться

1. Mac и телефон в одной Wi-Fi сети.
2. Иконка 💬 в строке меню → «Показать QR-код для телефона…» → отсканируй камерой.
3. Пиши в поле на телефоне — текст сразу появляется в вырезе.
   Для живых субтитров нажми 🎤 на клавиатуре телефона и говори.

При первом запуске macOS может спросить про входящие подключения / локальную сеть — разреши.

## API (порт 8765)

```bash
curl -X POST --data 'Привет' http://<ip-мака>:8765/text   # показать текст
curl "http://<ip-мака>:8765/text?t=Привет"                 # то же через GET
curl -X POST http://<ip-мака>:8765/clear                   # скрыть
```

Удобно для «Быстрых команд» на iPhone: действие «Получить содержимое URL», метод POST, тело — текст.

## Файлы

- `Sources/Islet/Notch.swift` — окно над вырезом и анимация «островка»
- `Sources/Islet/Server.swift` — HTTP-сервер в локальной сети
- `Sources/Islet/PhonePage.swift` — страница для телефона
- `Sources/Islet/main.swift` — меню в строке меню, QR-код, настройки
